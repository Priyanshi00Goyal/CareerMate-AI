# 🚀 CareerMate AI

> **Your AI-powered career guidance and professional growth companion.**

CareerMate AI is an intelligent career assistance platform designed to help users explore career paths, analyze resumes, identify skill gaps, create personalized learning roadmaps, track progress, and receive AI-powered career guidance.

Built using **Python, Streamlit, Machine Learning concepts, and Google's Gemini AI**, CareerMate AI provides an interactive platform for students and professionals to make more informed career decisions.

## ✨ Features

### 👤 Profile Management

Create and manage your professional profile to personalize your career journey.

### 📄 Resume Analyzer

Upload your resume and receive insights based on your skills and career profile.

### 🔍 Career Explorer

Explore different career paths and discover roles that match your skills and interests.

### 🧠 Career Assessment

Answer career-related questions to better understand suitable career options.

### 📊 Skill Gap Analysis

Identify the skills you currently have and discover the skills you need to develop for your target career.

### 🗺️ Personalized Career Roadmap

Get a structured roadmap to guide your career development journey.

### 📚 Learning Plan

Receive learning recommendations and organize your skill development process.

### 📈 Progress Tracking

Track your learning progress and monitor your growth over time.

### 📊 Analytics Dashboard

Visualize your career and learning progress through interactive analytics.

### 🤖 AI Career Mentor

Get AI-powered career guidance and assistance using **Google Gemini AI**.

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Priyanshi00Goyal/CareerMate-AI.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd CareerMate-AI
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate the Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS/Linux

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Configure Your API Key

CareerMate AI uses **Google Gemini AI** for AI-powered career guidance.

Store your API key securely using environment variables or Streamlit Secrets.

Example for Streamlit:

```toml
GEMINI_API_KEY = "your_api_key_here"
```

> ⚠️ Never upload your API key directly to GitHub.

### 7️⃣ Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.
